## 決まったこと（2026-07-27・第 1 段階で対応済み）

| 決定 | 対応 |
|------|------|
| ルートは README だけにする。ユーザーが実行するスクリプトは `script` へ | `script/`（bat・アイコン生成）、`src/`（本体）、`assets/`（アイコン）、`tools/`（Everything 本体）に分割。ビルドは **`script\build_exe2.bat` をダブルクリック**、出力は従来どおり `dist\Everysearch.exe` |
| `dist` には README だけ入れればよい | ico と icons のコピーを廃止 |
| ドラッグ＆ドロップは必要だが、いったん白紙でよい。だめなノウハウは残す | 動かないコードを削除し、失敗の内容を [development-guide.md](development-guide.md) §6 に記録 |
| 暗号化できるものは暗号化する | パスワードを Windows DPAPI で暗号化保存（[architecture.md](architecture.md) §8） |
| 「名前」列のソートは意図的でないので直す | ファイル名基準に修正 |
| 対象フォルダを選び直したらリアルタイム再検索 | 履歴選択・フォルダ選択…・× クリアの 3 か所で即再検索 |

ビルドは実機で確認済み（`dist\Everysearch.exe` 12.1 MB / 起動確認）。

## 第 2 段階（これから実装）

「実装候補」から格上げしたもの。上から着手予定。

| # | 項目 | 実装方針（変なら指摘してください） |
|---|------|-----------------------------------|
| 1 | 更新日時での絞り込み | フィルタチップの並びに期間の選択（全期間 / 1 週間 / 1 か月 / 3 か月 / 1 年）を追加。選択はチップ同様 `settings.json` に保存 |
| 2 | 表示件数の上限を変更できるようにする | フィルタ設定タブに「表示件数」欄（既定 200）。取得件数の上限（500・20000）は触らない |
| 3 | 検索キーワードの履歴 | 対象フォルダ欄と同じドロップダウン。ライブ検索の邪魔にならないよう **↓キーと空欄フォーカス時だけ**開く。Enter / 検索ボタンで確定したものを最大 20 件 |
| 4 | 結果一覧のエクスポート | 右クリックメニューに「一覧を CSV で保存」「一覧をコピー（タブ区切り）」。**表示中の行**が対象 |
| 5 | 対象フォルダの複数指定 | `"A";"B"` のようにセミコロン区切り。Everything 側は `<path:"A"|path:"B">` で OR。履歴は 1 行まるごとを 1 件として保持 |
| 6 | フィルタのプリセット切り替え | `settings.json` に名前付きのフィルタ定義一式を複数持たせ、検索画面に切り替えプルダウン。フィルタ設定タブで保存・削除 |
| 7 | ドラッグ＆ドロップの作り直し | UI スレッドを止めない作りが前提。目処が立たなければ見送り（コピーで代替できているため優先度は最後） |
