# Everysearch

型番・図番などの検索で、`-` と `_` の違いを意識せずに Everything を使える補助ツールです。

## できること

- 次の区切り文字をすべて同一視します: `-` / `_` / 半角スペース / 全角スペース
  - `REV757_0200_AA_00` → `REV757-0200-AA-00` にもヒット
  - `REV757 1055` や `REV757　1055` → `REV757-1055` / `REV757_1055` にもヒット
- ファイル名の途中一致もします
  - `694 1056` → `REV694-1056` / `REV694_1056` などにもヒット
- 対象フォルダを指定して検索範囲を限定
- サイズ・更新日時の表示、列ヘッダでのソート
- **種類フィルタ** … フォルダ / DWG / DXF / PDF / Excel / その他 の表示・非表示を切り替え
- 選択したファイルやフォルダを開く、パスのコピー
- Everything が別 PC で動いている場合の接続先設定

## 必要なもの

| 項目 | 内容 |
|------|------|
| OS | Windows |
| Python | 3.x（`tkinter` が使えること） |
| Everything | インストール済みで、**HTTP サーバーが有効**であること |

### Everything 側の設定

1. Everything を起動する
2. **ツール → オプション → HTTP サーバー**
3. HTTP サーバーを有効にする（既定ポートは多くが `8888`）
4. 他 PC から使う場合は、ファイアウォールでそのポートを許可する

ブラウザで `http://127.0.0.1:8888/` が開けば準備完了です。

## 起動方法

### EXE（推奨）

`dist\Everysearch.exe` をダブルクリックします。  
Python のインストールは不要です。

再ビルドする場合:

```bat
build_exe.bat
```

（`build_icon.py` でアイコン生成 → PyInstaller で EXE 作成）

### Python から起動

フォルダ内の `起動.bat` をダブルクリックするか、次を実行します。

```bat
py everything_gui_search.py
```

または

```bat
python everything_gui_search.py
```

## 使い方

### 検索タブ

1. **検索** 欄に型番・図番を入力（例: `REV757_0200_AA_00`）
2. **対象フォルダ** を必要に応じて指定
   - `"\\サーバー\共有\フォルダ"` のように **ダブルクォーテーション付き** で書く
   - 入力欄をクリック／フォーカスすると **履歴一覧** が出ます（クリックで選択）
   - 履歴の右端 **×** … その履歴だけ削除
   - 一覧を出していないときの入力欄横 **×** … 入力を消して **全体検索**
   - 一覧表示中の入力欄横 **×** … 履歴一覧を閉じる
   - **フォルダ選択…** で GUI から選ぶこともできます
   - 検索やフォルダ選択で使ったパスは履歴に自動追加されます（最大 20 件）
3. **検索** ボタン、または Enter で実行
4. 結果一覧から項目を選び、下部ボタンで操作
   - **選択ファイルを開く** … ファイルを開く（ダブルクリックでも可）
   - **選択フォルダを開く** … 親フォルダをエクスプローラーで開く
   - **パスをコピー** … フルパスをクリップボードへ

### 並び替え

結果テーブルの列ヘッダ（種類 / 名前 / 場所 / サイズ / 更新日時）をクリックします。  
同じ列をもう一度クリックすると昇順・降順が切り替わります。  
表示はソート後の上位 100 件までです。

### 種類フィルタ

画面下の **種類フィルタ** のチップ（フォルダ / DWG / DXF / PDF / Excel / その他）をクリックすると、その種類の **表示 / 非表示** が切り替わります。

- **明るい色** … 表示中
- **暗いグレー（ダークアウト）** … 非表示（一覧から除外）

もう一度クリックすると再表示されます。色の対応は次のとおりです。

| 色（表示中） | 種類 |
|--------------|------|
| 薄い黄 | フォルダ |
| 薄い青 | DWG |
| 薄い灰 | DXF |
| 薄い赤 | PDF |
| 薄い緑 | Excel |
| 白 | その他 |

### 使い方タブ

- 簡単な操作手順
- **Everything のダウンロード** リンク（公式: https://www.voidtools.com/ ）

### 接続設定タブ

Everything が **この PC 以外** で動いているときに使います。

| 項目 | 説明 |
|------|------|
| ホスト / IP | 例: `127.0.0.1` または `192.168.x.x` |
| ポート | HTTP サーバーのポート（例: `8888`） |
| ユーザー / パスワード | Everything で認証を設定している場合のみ |

**設定を保存** で `settings.json` に書き込みます。  
**接続テスト** で疎通確認できます。

## 設定ファイル

初回保存後、同じフォルダに `settings.json` ができます。

```json
{
  "host": "127.0.0.1",
  "port": 8888,
  "user": "",
  "password": "",
  "search_folder": "\"\\\\LS210D820\\sekkei\\...\""
}
```

- 接続先や最後に使った対象フォルダを保持します
- 手編集してもよいですが、通常はアプリの「接続設定」から変更してください

## うまく動かないとき

| 症状 | 確認すること |
|------|----------------|
| 接続エラー | Everything が起動しているか、HTTP サーバーが有効か、ホストとポートが合っているか |
| 0 件になる | 対象フォルダのパスが正しいか。`"パス"` のように引用符付きか。空欄で全体検索して比較 |
| 画面が開かない | Python の `tkinter` が使えるか（`py -3 -c "import tkinter"`） |
| 他 PC から接続できない | Everything 側の待受設定とファイアウォール |

```

  build_exe.bat             … アイコン生成 + EXE ビルド
```

## アイコン

薄い青のモダンな虫眼鏡デザインです（参考の検索アイコンをベースに再設計）。

| ファイル | 内容 |
|----------|------|
| `everysearch.ico` | Windows 用マルチサイズ ICO |
| `icons/everysearch_16.png` 〜 `_256.png` | 16 / 20 / 24 / 32 / 40 / 48 / 64 / 72 / 96 / 128 / 256 |
| `icons/everysearch_master.png` | 256px マスター |

EXE のファイルアイコンとウィンドウアイコンの両方に使用します。

## 補足

- Everything 本体を改造するのではなく、検索語を整形して HTTP API に渡しています
- 入力中の `-` / `_` / 半角スペース / 全角スペースは内部で `[-_\x20\x{3000}]` として扱われます
- 表示上の対象フォルダは `"パス"` 形式を推奨します（検索時に自動で正規化します）
